### Drill 1 – Filter Safe Deliveries Iloilo Express

### Scenario

A delivery company operating in Iloilo City receives orders across various districts during heavy rainfall. 

The program checks the status of each area, filters out flooded routes, and generates dispatch receipts for safe locations.

### Concepts Used

- Functions
- Arrays
- Objects
- Loops (`for` statement)
- Conditional Statements (`if`)
- String interpolation
